# Tester DSL 语法规范

Tester 是一种面向 CAN 总线 / 汽车 ECU 测试的领域专用语言。一个 Tester 文件由三部分组成：

```
配置块（tset...tend）     ← 设备与诊断参数
测试集（ttitle...ttitle-end） ← 包含多个测试用例
  测试用例（tstart...tend）   ← 包含测试命令
```

## 注释

```
// 单行注释
tnote = 这也是注释（备注命令）
```

## 配置块

```
tset
    <配置命令...>
tend
```

配置块使用 `tset` / `tend` 包裹，内部包含通道初始化和诊断配置命令。

### tcaninit — 通道初始化

```
tcaninit <设备ID>,<设备索引>,<通道索引>,<仲裁域波特率>[,<数据域波特率>]
```

| 参数 | 说明 |
|------|------|
| 设备ID | CAN 设备类型 ID（整数） |
| 设备索引 | 设备序号（从 0 开始） |
| 通道索引 | 设备上的通道序号（从 0 开始） |
| 仲裁域波特率 | 仲裁域波特率，单位 bps |
| 数据域波特率 | （可选）数据域波特率，CAN-FD 时使用 |

示例：
```
tcaninit 4,0,0,500000,2000000
```

### tcans_ch_def — 通道别名定义

```
tcans_ch_def <别名>,<通道索引>
```

为通道定义别名，后续命令中可用别名代替通道索引。

### tdiagnose_rid — 诊断响应 ID

```
tdiagnose_rid <十六进制ID>
```

### tdiagnose_sid — 诊断请求 ID

```
tdiagnose_sid <十六进制ID>
```

### tdiagnose_keyk — 诊断安全访问密钥

```
tdiagnose_keyk <十六进制密钥>
```

### tdiagnose_dtc — 故障码定义

```
tdiagnose_dtc <故障码>,<故障描述>
```

示例：
```
tdiagnose_dtc C10087,发动机过热
tdiagnose_dtc U11487,通信丢失
```

## 测试集与测试用例

```
ttitle=<测试集名称>
    [序号] tstart=<测试用例名称>
        <测试命令...>
    tend
ttitle-end
```

- `ttitle=` 开始测试集，`ttitle-end` 结束
- `tstart=` 开始测试用例，`tend` 结束
- 序号为可选的数字前缀

示例：
```
ttitle=网络管理测试
    1 tstart=节点唤醒验证
        tcans 18FF0012,01-02-03-04-05-06-07-08,100,1
        tcanr 18FF0013,0.0-3.7,01020304,3000
    tend
    2 tstart=节点休眠验证
        tdelay 5000
        tcanr 18FF0013,0.0-0.7,00,3000
    tend
ttitle-end
```

## 测试命令

### tcans — 发送 CAN 报文

```
tcans [通道,]<报文ID>,<数据>,<发送间隔>,<发送次数>
```

| 参数 | 说明 |
|------|------|
| 通道 | （可选）项目通道号，省略时使用默认通道 |
| 报文ID | 十六进制报文 ID |
| 数据 | 十六进制数据字节，用 `-` 或空格分隔 |
| 发送间隔 | 发送间隔，单位毫秒 |
| 发送次数 | 发送次数 |

示例：
```
tcans 18FF0012,11-22-33-44-55-66-77-88,100,1
tcans 1,18FF0012,AA-BB-CC-DD,500,10    // 指定通道 1
```

### tcanr — 接收 CAN 报文

tcanr 有三种用法：

**位域对比**（检查指定位域是否匹配期望值）：
```
tcanr [通道,]<报文ID>,<位域范围>,<期望值>,<超时时间>
```

**整帧对比**（检查完整数据是否匹配）：
```
tcanr [通道,]<报文ID>,<期望数据>,<超时时间>
```

**打印模式**（打印接收到的数据，不做校验）：
```
tcanr [通道,]<报文ID>,<位域范围>,print
```

| 参数 | 说明 |
|------|------|
| 通道 | （可选）项目通道号 |
| 报文ID | 十六进制报文 ID |
| 位域范围 | 格式为 `起始字节.起始位-结束字节.结束位`，如 `0.0-3.7` |
| 期望值 | 十六进制期望数据 |
| 超时时间 | 等待超时，单位毫秒 |

示例：
```
tcanr 18FF0013,0.0-3.7,11223344,3000       // 位域对比
tcanr 18FF0013,11-22-33-44-55-66-77-88,3000 // 整帧对比
tcanr 18FF0013,0.0-3.7,print                // 打印模式
tcanr 1,18FF0013,0.0-0.7,FF,2000            // 指定通道
```

### tdelay — 延时

```
tdelay <毫秒数>
```

### tconfirm — 人工确认

```
tconfirm <提示信息>
```

暂停执行，等待操作人员确认后继续。

### tnote — 备注

```
tnote = <备注内容>
```

等同于注释，用于对命令进行说明。

## 位域与枚举（高级）

### tenum — 枚举定义

```
tenum <枚举名> <值>=<含义>,<值>=<含义>,...
```

定义一组命名值，供 bitfield 引用。

示例：
```
tenum GearState 0=P,1=R,2=N,3=D
```

### tbitfield — 位域映射定义

```
tbitfield <名称> <报文ID> <字段映射>...
```

定义报文的位域到信号名的映射关系。

## 完整示例

```
// ======== 设备配置 ========
tset
    // CAN-FD 通道初始化
    tcaninit 4,0,0,500000,2000000

    // 诊断配置
    tdiagnose_rid 7A1
    tdiagnose_sid 7A9
    tdiagnose_keyk 10086

    // 故障码
    tdiagnose_dtc C10087,发动机过热故障
    tdiagnose_dtc U11487,CAN通信丢失
tend

// ======== 功能测试 ========
ttitle=发动机控制模块测试
    1 tstart=基本通信验证
        tnote = 发送请求报文并验证响应
        tcans 18FF0012,01-02-03-04-05-06-07-08,100,1
        tdelay 200
        tcanr 18FF0013,0.0-3.7,01020304,3000
    tend

    2 tstart=诊断响应测试
        tcans 7A9,02-10-01-00-00-00-00-00,0,1
        tcanr 7A1,0.0-2.7,026701,3000
    tend

    3 tstart=人工检查
        tconfirm 请确认仪表盘指示灯是否点亮
    tend
ttitle-end
```
